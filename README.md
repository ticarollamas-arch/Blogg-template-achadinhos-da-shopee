# Shopee Blogger Template Builder 🛍️

Gerador e personalizador profissional de templates XML para blogs de afiliados da **Shopee** no **Blogger / Blogspot**. Crie uma loja virtual moderna, rápida e 100% responsiva sem precisar programar!

---

## 🚀 Funcionalidades

- **Personalização Visual em Tempo Real:**
  - Cores do tema (Cor primária, secundária e fundo).
  - Nome da loja, descrição e links de redes sociais (Instagram, WhatsApp).
  - Quantidade de colunas e estilo dos cartões de produtos.
- **Carrossel de Destaques Automático:**
  - Banners promocionais com rotação suave e adaptável a telas menores.
- **Simulador Interativo (Live Preview):**
  - Visualize instantaneamente cada alteração antes de salvar.
  - Teste visualização dos produtos, botões de compra pulsantes e etiquetas (badges) de desconto.
- **Gerador de Postagens / Produtos:**
  - Criação rápida de cards de produto com link de afiliado Shopee.
  - Geração automática do código HTML pronto para copiar e colar no editor do Blogger.
- **Exportação do Template XML Oficial:**
  - Código limpo e compatível com as diretrizes e servidores do Blogger.
  - Suporte integrado a slots de monetização com Google AdSense.
  - Páginas de políticas (Sobre, Contato, Privacidade, Termos).

## 📦 Como Executar o Projeto Localmente

### Pré-requisitos
- [Node.js](https://nodejs.org/) (versão 18 ou superior)
- `npm` ou `yarn` / `bun`

### Passo a Passo

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   cd SEU_REPOSITORIO
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no seu navegador:**
   ```
   http://localhost:3000
   ```

5. **Gerar a build de produção:**
   ```bash
   npm run build
   ```

## 📖 Como Instalar o Template no Blogger

1. No aplicativo, configure os dados da sua loja, cores e banners.
2. Na aba **"3. Código XML & Instalação"**, clique em **"Copiar Código XML"** ou **"Baixar Arquivo .xml"**.
3. Acesse o painel do seu blog em [blogger.com](https://www.blogger.com).
4. No menu lateral esquerdo, clique em **Tema** (Theme).
5. Clique na setinha ao lado do botão laranja "Personalizar" e escolha **Editar HTML** (ou **Restaurar** para enviar o arquivo baixado).
6. Selecione todo o código antigo, apague e cole o novo código XML gerado.
7. Clique no botão de **Salvar** (ícone de disquete) no canto superior direito.
